# Scope & privacy — Kids Studio

## Purpose of this repository

This public repository exists so recruiters, clients, and collaborators can evaluate engineering depth **without** accessing proprietary source code or sensitive data.

## Included

- Architecture and workflow descriptions
- Technology choices and trade-offs
- Skills mapping to real implementation work in the private repo
- Links to live demos where appropriate

## Excluded

- API keys, JWT secrets, seed owner credentials
- Owner-generated characters/video assets (private IP)
- Internal FAL spend guardrail playbooks

## Author role

Solo builder — pipeline architecture and safety engineering
